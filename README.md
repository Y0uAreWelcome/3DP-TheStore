# 3dp

Excited to share my latest project: A fully automated, production-grade e-commerce web stack for 3D printed FPV parts!

As a creator and maker, I wanted a seamless storefront where I could add new items, update prices, or change descriptions directly in a database and have them instantly go live without touching code or manually managing third-party product catalogs.

Here is what went into building this modern web architecture:

    Frontend: Clean, responsive HTML/CSS/JS interface optimized for fast loading and mobile shopping.

    Database & Security: Powered by Supabase with strict Row Level Security (RLS) policies to protect data while delivering instant content.

    Backend & Payments: A custom Node.js/Express server that dynamically generates and handles secure checkout sessions via Stripe on the fly.

    Hosting & Deployment: Managed through GitHub for version control, deployed via Render for reliable server execution.

    Security & Performance: Secured and accelerated globally using Cloudflare for DNS management, SSL protection, and edge optimization.

It’s been an incredible journey bringing this stack together from scratch. Check out the setup and happy printing! 🛠️🖨️
